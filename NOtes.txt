New Yaml creation
kubectl run nginx-yaml --image=nginx --dry-run=client -o yaml > test_nginx.yml

TO run a pod from file
	c:\GITHUB\labdemo>kubectl create -f test_nginx.yaml  (creats )
	or 
	kubectl apply -f test_nginx.yaml  ( will check the differences in the already running pod and runs it)
	

Runing shell commands inside a pod
c:\GITHUB\labdemo>kubectl exec -it nginx-docs -- /bin/bash   # if bash exist

c:\GITHUB\labdemo>kubectl exec -it nginx-docs -- /bin/sh # if sh exist


Install packages inside the pod

go to back as mention above and then

apt install <name of the package>

root@httpd:/usr/local/apache2# apt install iputils-ping  # for pinging
